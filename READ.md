## Выбранный вариант
Вариант 6 — Тема: «Любитель кино и сериалов». Кинематографичная сетка и hover-эффект.

## Что было сделано
В работе выполнил все требования из методички по своему варианту:
* Подключил стили всеми 3 способами:
  * Внешний файл (`style.css`).
  * Внутренний тег `<style>` в `<head>` (задал ширину и фон для блока `<aside>`).
  * Inline-стиль в HTML (сделал жирный шрифт `font-weight: 700` для заголовка в `<header>`).
* В `:root` вынес CSS-переменные: основной чёрный цвет, акцентный золотой, красный для фокуса, а также цвета текста.
* Проверил контрастность текста — получилось значительно выше требуемых 4.5:1, читать удобно.
* Использовал все виды позиционирования: `static` для структуры, `relative` для карточек и `absolute` для оверлея.
* Секцию «Проекты» переделал в сетку из 3 колонок с помощью `display: grid`.
* Настроил состояния элементов: 
  * при наведении (`:hover`) на карточку проекта появляется полупрозрачный оверлей и увеличивается заголовок;
  * при фокусе (`:focus`) на кнопку отправки формы загорается красная рамка (цвет премии «Оскар»);
