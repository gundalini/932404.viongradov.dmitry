# Лабораторная работа №3. Вёрстка макета с помощью Flexbox и Grid

Выполнил студент группы 932404 Виноградов Дмитрий.
Ветка проекта: lab3

## Описание проекта
В этой работе страница была переведена на адаптивный дизайн (Responsive Web Design). Главная цель - освоить современные технологии Flexbox для одномерных макетов и CSS Grid для двумерных сеток. Теперь интерфейс страницы корректно подстраивается под размеры экрана десктопа, планшета и мобильного телефона без появления горизонтальной прокрутки.

## Выбранный вариант
Вариант 6 — Тема: «Любитель кино и сериалов» (киноафиша и рейтинг).

## Что было сделано
В работе выполнил все требования из методички по своему варианту:
* Flexbox-вёрстка:
  * Навигационное меню (`.nav-links`) стало адаптивным Flex-контейнером.
  * Создана новая секция «Топ-фильмов для просмотра». Карточки фильмов выстроены в ряд (flex-карточки), внутри каждой есть миниатюрный постер, название, жанр и год.
* Grid-галерея:
  * Создана секция «Любимые режиссёры». Реализована через CSS Grid в формате сетки 2×2 (фото, имя и один знаковый фильм).
* Семантическая разметка:
  * Использовал семантически верные теги по ТЗ: `<article>` для карточек с фильмами, а также `<figure>` и `<figcaption>` для галереи режиссёров.
* **Адаптивность (Медиа-запросы `@media`):**
  * **Десктоп:** Flex-карточки (фильмы) — 3 колонки, Grid-галерея (режиссёры) — 2 колонки.
  * **Планшет (до 992px):** Flex-карточки перестраиваются в 2 колонки.
  * **Мобильный телефон (до 768px):** Всё (навигация, фильмы, проекты и режиссёры) выстраивается в 1 сплошную колонку для удобного скролла.
* Доступность и UI:
  * Контрастность текста (светлый на тёмном) сохранена и составляет ≥ 4.5:1.



  Добавил крутушую штуку- плавную прокрутку по странице (`scroll-behavior: smooth`) при клике на ссылки в навигации. Стандартная работа мне жить не давала

## Процесс и доработка
Продолжая улучшать свой проект киномана, столкнулся с новыми трудностями при внедрении адаптивности. В первую очередь пришлось полностью отказаться от старого блока `<aside>`, так как его жёсткая ширина ломала вид на мобильных устройствах. 

Самая большая проблема возникла с фотографиями. При использовании `object-fit: cover` браузер пытался впихнуть фото в жёсткие рамки по высоте, из-за чего постерам обрезало края, а режиссёрам (в частности Нолану и Бэю) буквально срезало половину лица. Вновь обратился за советом к нейронке, вместе мы разобрались с пропорциями. Заменили жёсткую высоту на свойство `aspect-ratio`: постерам задали классический киноформат `2/3`, а портретам — квадрат `1/1`, плюс настроили фокус (`object-position`), чтобы лица всегда оставались в кадре. 

Результат тестировал через эмуляторы мобильных устройств в DevTools (F12) — горизонтальный скролл полностью отсутствует.

Код по-прежнему проверен валидаторами: https://jigsaw.w3.org/css-validator/validator и https://validator.w3.org.
