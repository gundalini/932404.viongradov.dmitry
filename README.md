## Тема и вариант
Вариант 6 — Тема: «Любитель кино и сериалов» (список фильмов к просмотру).


## Реализованный функционал
* Поиск элементов DOM с использованием методов `getElementById` и `querySelector`/`querySelectorAll`, а также обработка ошибок с проверкой существования элементов перед манипуляциями.
* Динамическое создание строк таблицы (`<tr>`), ячеек (`<td>`) и кнопок управления с помощью `document.createElement()` и добавление их в DOM через `appendChild()`.
* Добавление фильмов в список через интерактивные диалоговые окна `prompt()` с проверкой корректности введённых данных (название и год).
* Изменение состояния элементов:
  * Переключение статуса фильма («К просмотру» / «Просмотрено»).
  * Удаление выбранного фильма из таблицы.
  * Очистка всего списка фильмов с проверкой на пустоту и подтверждением действия.
* Переключение темы оформления (светлая/тёмная) с помощью кнопки, изменяющей класс у `<body>` (`theme-light` / `theme-dark`), с адаптацией цветовой гаммы всех блоков сайта (шапки, карточек проектов, режиссёров и форм).
* Интерактивное скрытие и показ таблицы фильмов по кнопке с динамическим изменением текста на панели управления («Скрыть таблицу» / «Показать таблицу»).
* Сохранение состояния списка фильмов и выбранной темы оформления в `localStorage` и их автовосстановление при перезагрузке страницы.

## Приколы во время выполнения лабы
* Изначально класс `.hidden` вешался на всю секцию целиком вместе с панелью управления. В итоге при нажатии на «Скрыть таблицу» скрывалась и сама кнопка, из-за чего вернуть таблицу обратно на экран было невозможно. Проблему удалось решить обёрткой самой таблицы в отдельный `<div id="table-container">`, благодаря чему, теперь все управления всегда остаются на виду.
* При тестировании переключения темы шапка страницы, карточки проектов, любимых режиссёров и фильмов оставались тёмными. Все из-за строгих параметров, которые я указал в css файле. Все цвета были переведены на гибкие CSS-переменные и теперь сайт переключает тему четенько.
